# Flapi Bord

A Flappy Bird clone game built with HTML5 Canvas and vanilla JavaScript.

## Description

Flapi Bord is a simple browser-based game inspired by the classic Flappy Bird. Navigate your bird through obstacles by jumping at the right time and try to achieve the highest score possible!

## Features

- Classic Flappy Bird gameplay mechanics
- Score tracking
- Responsive canvas rendering
- Keyboard and touch controls
- Sound effects

## How to Play

1. Open `index.html` in your web browser
2. Click the "Başla" button or press the **Space** key to start
3. Press **Space** or **W** to make the bird jump
4. Press **P** to pause/unpause the game
5. Avoid hitting the pipes and the ground
6. Try to get the highest score!

## Controls

- **Space** or **W** - Jump
- **P** - Pause/Unpause
- **Touch** (mobile) - Jump

## Installation

No installation required! Simply clone or download this repository and open `index.html` in a web browser.

```bash
git clone <repository-url>
cd flapi-bord
# Open index.html in your browser
```
